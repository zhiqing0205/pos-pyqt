## 系统简介

本系统是一套专为中小型超市、便利店设计的**收银与库存管理系统**，基于 PyQt5 桌面框架开发，采用现代化的 Fluent Design 风格界面。

**核心功能包括：**

- **扫码收银**：支持 USB 条码扫码枪即扫即录，快速结账
- **商品管理**：支持条码、名称、分类、进售价、库存等完整商品信息维护
- **进货管理**：扫码入库，自动更新库存和进价
- **用户管理**：管理员 / 店员角色分离，权限隔离
- **数据统计**：仪表盘实时展示营业数据、图表、排行
- **销售记录**：完整的交易历史查询与详情查看
- **支付方式**：支持现金、微信支付、支付宝三种收款方式
- **数据备份**：每日定时自动备份 + 手动备份 + 导入导出

**系统采用本地 SQLite 数据库存储数据，无需联网即可使用，适合单机或小规模门店部署。**


## 安装与启动

### 方式一：直接运行（推荐开发者）

确保已安装 Python 3.8 及以上版本，并安装依赖：

```bash
pip install PyQt5==5.15.11 PyQt-Fluent-Widgets==1.11.1
```

启动程序：

```bash
python main.py
```

### 方式二：使用预编译版本

前往 [GitHub Releases](https://github.com/zhiqing0205/pos-pyqt/releases) 下载对应平台的安装包：

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows (x64) | `pos-pyqt-windows-x64-版本号-setup.exe` | 安装程序，推荐使用 |
| Windows (x64) | `pos-pyqt-windows-x64-版本号-portable.zip` | 免安装便携版，解压即用 |
| macOS (ARM64) | `pos-pyqt-macos-arm64-版本号.dmg` | macOS 磁盘映像 |
| Linux (x64) | `pos-pyqt-linux-x64-版本号.tar.gz` | Linux 压缩包，解压后运行 |

### 首次启动

系统首次启动时会自动完成以下初始化：

1. 创建数据库文件 `app/data/pos.db`
2. 创建备份目录 `app/data/backups/`
3. 初始化数据库表结构
4. 创建默认管理员账户（用户名 `admin`，密码 `admin123`）
5. 创建 2 个演示店员账户（张店员 / 李店员，密码 `123456`）
6. 导入 26 种预设商品数据（涵盖饮料、水、奶品、酒、方便面、零食、日用品 7 个分类）
7. 生成近 7 天的演示交易和进货记录

### 添加商品到购物车

有两种方式可将商品添加到购物车：

#### 方式一：条码扫码枪（推荐）

1. 确保焦点不在任何文本输入框中（点击页面空白区域即可）
2. 使用 USB 条码扫码枪扫描商品条码
3. 扫码枪会自动输入条码并按下回车键
4. 系统自动识别商品并加入购物车
5. 若商品已在购物车中，数量自动 +1
6. 若商品不存在，显示红色错误提示

> 扫码枪通过模拟键盘输入工作，系统使用全局事件过滤器捕获输入。连续按键会进入缓冲区，100 毫秒无新输入后自动清空。

#### 方式二：点击商品按钮

1. 在右侧面板中选择商品分类（如「饮料」「零食」等），或选择「全部」查看所有商品。分类标签的显示顺序由「商品分类」页面中的排序值决定
2. 点击对应的商品按钮
3. 商品自动加入购物车，若已存在则数量 +1

### 管理购物车

购物车表格显示以下列：

| 列名 | 说明 |
|------|------|
| # | 商品序号 |
| 商品名称 | 商品名称 |
| 单价 | 商品售价 |
| 数量 | 当前购买数量，可通过 ＋/－ 按钮调整 |
| 折扣 | 单品折扣率，如「85%」表示 85 折 |
| 小计 | 单价 × 数量 × 折扣率 |
| 操作 | 删除按钮 |

#### 调整数量

- 点击行右侧的 **＋** 按钮增加数量
- 点击 **－** 按钮减少数量（减至 0 时自动删除该商品）

#### 双击编辑

双击购物车中的任意商品行，弹出编辑对话框，可执行以下操作：

- **修改数量**：通过数值输入框精确设置购买数量
- **修改折扣**：输入折扣百分比（如输入 85 表示 85 折）
- **删除商品**：点击红色「删除此商品」按钮

#### 清空购物车

点击操作栏的「清空」按钮可一次性清空所有商品。


### 整单折扣

按 **F4** 或点击「折扣」按钮打开整单折扣对话框。

- 输入折扣百分比，例如输入 **85** 表示全单打 **85 折**（即总价 × 0.85）
- 折扣应用后，下方的「折扣优惠」和「应收金额」会实时更新
- 整单折扣与单品折扣叠加计算

### 库存校验与忽略库存模式

操作栏上有一个**「忽略库存」切换开关**，默认为**开启状态**。

| 模式 | 库存不足时的行为 |
|------|------------------|
| 忽略库存 **开启**（默认） | 显示黄色警告提示，但**不阻止**操作。可继续增加数量和结账 |
| 忽略库存 **关闭** | 显示红色错误提示，**阻止**增加数量和结账 |

库存校验发生在以下时机：

- 添加商品到购物车时
- 点击 ＋ 按钮增加数量时
- 双击修改数量时
- 点击结账时（逐一检查所有商品）


### 结账

购物车中有商品后，按 **F12** 或点击「结账」按钮打开结账对话框。

<figure>
<img src="screenshots/checkout.png" width="42%">
<figcaption>图：结账对话框</figcaption>
</figure>

#### 结账步骤

1. 确认页面顶部显示的**应收金额**（红色大字）
2. 选择**付款方式**：
   - **现金**：输入收款金额，系统自动计算找零
   - **支付宝**：可选填支付凭证号（需先在「支付设置」中配置支付宝参数后才会显示）
   - **微信支付**：可选填支付凭证号（需先在「支付设置」中配置微信支付参数后才会显示）
3. 点击「确认结账」完成交易

> 现金支付始终可用。支付宝和微信支付需管理员在「支付设置」页面填写全部配置字段并保存后，结账时才会出现对应选项。详见[支付设置](#支付设置管理员)章节。

#### 结账完成后

- 系统自动生成交易单号（格式 `TXN` + 时间戳）
- 交易记录和商品明细写入数据库
- 自动扣减相关商品库存
- 购物车清空，折扣率重置
- 界面顶部显示绿色「交易完成」提示

## 常见使用场景

### 场景一：日常收银

1. 店员登录系统，自动进入收银页面
2. 使用扫码枪逐一扫描顾客商品，购物车自动添加
3. 如需调整数量，点击 ＋/－ 按钮或双击商品行精确修改
4. 如有优惠活动，按 F4 设置整单折扣
5. 按 F12 结账，选择支付方式，完成交易
6. 系统自动清空购物车，准备服务下一位顾客

### 场景二：新商品上架

1. 管理员登录，进入商品管理页面
2. 使用扫码枪扫描新商品条码
3. 系统检测到该条码不存在，自动弹出添加对话框并预填条码
4. 填写商品名称、分类、售价等信息，保存
5. 切换到进货管理页面，扫码该商品进行首批入库

### 场景三：每日进货

1. 管理员登录，进入进货管理页面
2. 逐一扫描到货商品条码
3. 在弹出的入库对话框中输入进货数量和进价
4. 确认后库存自动增加
5. 所有进货记录自动保存在记录表中，便于后续核查

### 场景四：查看经营状况

1. 管理员登录，进入仪表盘页面
2. 查看今日和本月的销售数据
3. 通过柱状图了解近 7 天的营业额趋势
4. 通过饼图了解各分类的销售占比和支付方式分布
5. 查看热销商品排行和库存预警列表
6. 浏览最近交易列表快速了解销售动态

### 场景五：数据备份与恢复

1. 管理员进入备份管理页面
2. 确认自动备份设置（时间、文件夹、关闭前备份）
3. 如需手动备份，点击「立即备份」
4. 如需迁移到新设备，使用「导出数据库」
5. 如数据出现问题，从备份列表中选择合适的时间点点击「恢复」


## 常见问题与排查

### 扫码枪无法识别

**现象**：扫码后无任何反应。

**排查**：

- 确保扫码枪为 USB HID 模式（模拟键盘输入 + 回车后缀）
- 确保焦点不在文本输入框中（如搜索框、条码输入框等），否则扫码内容会输入到文本框中而非被系统全局捕获
- 点击页面空白区域使焦点脱离输入框后重试

### 支付宝/微信选项不显示

**现象**：结账时只有"现金"选项。

**排查**：

- 进入「支付设置」页面，确认所有字段已正确填写并保存
- 微信需填写 4 个字段（APPID、APPSECRET、商户号、支付密钥）
- 支付宝需填写 3 个字段（APPID、支付宝公钥、商户私钥）

### 超卖警告

**现象**：结账时提示库存不足。

**排查**：

- 如果「忽略库存」开关为开启状态，警告不会阻止操作，可以继续结账
- 如果需要严格管控库存，关闭「忽略库存」开关，此时库存不足会阻止结账
- 在进货管理中扫码补充库存

### 恢复备份后数据未更新

**现象**：恢复备份或导入数据库后，界面仍显示旧数据。

**排查**：

- 恢复/导入操作完成后必须**重启程序**才能生效
- 关闭程序后重新打开即可

### 购物车序号显示不全

**现象**：购物车商品超过 9 件后序号不显示。

**排查**：

- 此问题已在 v1.3.2 中修复。如遇此问题请升级到最新版本
